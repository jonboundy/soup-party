# Soup Party preview assets

Jon chose the cascading soup bowl for the browser icon on 2026-10-13. He first chose a dark “Electric Boogaloo” sequel design for link previews, then on 2026-10-14 replaced it with the favicon bowl beside “Soup Party”, because the sequel card carried too much (the URL, tagline, date and title).

- `src/app/icon.svg` copies the paths, stroke width and tomato palette from `src/components/home/soup-cascade.tsx`, with a white foot at Jon's request. Its outline switches to cream in dark browser tabs.
- `src/app/favicon.ico` is the same drawing on a cream background at 16, 32, 48 and 64 pixels, for browsers that use the ICO fallback. `src/app/apple-icon.png` is a padded 180-pixel version for home screens.
- `src/app/opengraph-image.png` is the selected 1200 × 630 link preview: the favicon's bowl in its light colours beside “Soup Party” in Geist 600, on the site's off-white. It carries no date, URL, tagline or sequel title; apps print the page title (“Soup Party 2: Electric Boogaloo”) and domain beneath it. The bowl's body (rim to foot, not the steam) is centred on the capital height, and that line is the image's middle; the lockup is centred left to right on its rendered pixels. The editable source is `link-preview.html` beside this file. It loads Geist from `node_modules/next`, so run `npm install` first, then open the HTML at a 1200 × 630 browser viewport and capture it at a device scale factor of 1 to re-export the PNG. The positions are fixed pixel values; re-centre them if the wording or size changes.

Next.js discovers these files automatically. The root layout supplies the production metadata base and the large Twitter card; the homepage supplies the event's Open Graph title and description. Twitter uses the same Open Graph image, so there is one full-size asset to maintain.
